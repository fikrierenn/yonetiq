# YonetIQ Kurumsal Yönetim Portalı

YonetIQ, .NET 10 Blazor Server tabanlı, modern ve yapay zeka destekli bir kurumsal yönetim sistemidir.

## 🚀 Hızlı Başlangıç
Uygulamayı yerel ortamınızda çalıştırmak için:
```powershell
dotnet run --project yonetiq
```

## 📚 Dokümantasyon
Proje ile ilgili detaylı bilgilere aşağıdaki rehberlerden ulaşabilirsiniz:

- 🏗️ **[Geliştirici Rehberi (DEVELOPER_GUIDE.md)](DEVELOPER_GUIDE.md)**: Mimari, teknik standartlar ve veritabanı yapısı.
- 📋 **[Proje Rehberi (PROJECT_GUIDE.md)](PROJECT_GUIDE.md)**: Proje vizyonu ve modül özetleri.
- 👤 **[Kullanıcı Rehberi (USER_GUIDE.md)](USER_GUIDE.md)**: Son kullanıcılar için özellik kullanımı.
- 🎓 **[Eğitim Kitapçığı (TRAINING_MANUAL.md)](TRAINING_MANUAL.md)**: Örnek senaryolar ve eğitim akışları.

## 🛠️ Temel Özellikler
- **Canlı Dashboard:** Gerçek zamanlı KPI ve verimlilik takibi.
- **Görev İzlenebilirliği:** Toplantı kararlarından otomatik görev oluşturma ve uçtan uca takip.
- **AI Entegrasyonu:** Gemini API ile SQL üretimi ve akıllı öneriler.
- **Modern UI:** Glassmorphism ve dinamik temalar içeren `yi-` tasarım dili.
